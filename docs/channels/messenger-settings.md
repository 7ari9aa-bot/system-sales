# إعدادات مسنجر: إيه اللي اتبنى، وإيه اللي ميتا نفسها وقّفته

كل سطر هنا إما كود موجود في الريبو أو صفحة من توثيق ميتا. مفيش بند مكتوب بالتخمين.

## اللي اتبنى

| البند | الملف | إيه اللي بيحصل |
|---|---|---|
| نص الترحيب، زرار Get Started، القائمة الثابتة، أسئلة ice breakers | `backend/app/modules/conversations/gateway/messenger_profile.py` | كل واحد بيتبعت للـ `/me/messenger_profile` بالشكل اللي ميتا بتقبله، وحدود ميتا نفسها (٥ عناصر قائمة، ٣ أسئلة، ١٦٠ حرف للترحيب، ٨٠ للسؤال) بترفض قبل النداء |
| تصنيفات المحادثات (labels) | نفس الملف | `add_labels` / `remove_labels` لكل PSID |
| قراءة المحادثات القديمة عند أول ربط | `backend/app/modules/conversations/messenger_backfill_service.py` | بتحوّل اللي اتقرأ من Conversation API لرسائل حقيقية |
| مصالحة دورية | `backend/app/workers/messenger_backfill_worker.py` | كل ٦ ساعات لكل صفحة مربوطة (ساعة لو آخر مرة فشلت)، والمهمة متسجلة في الـ scheduler باسم `messenger.backfill_reconcile` |
| تحكّم المحادثة (take / pass / request thread control) | `backend/app/modules/conversations/gateway/ingest.py` (`apply_handover`) | take بيوقف الرد الآلي، pass بيرجّعه، request مابيغيّرش حاجة |

حدود مقاسة في الكود: ٢٥ محادثة في الصفحة، ١٠٠ محادثة كحد أقصى، ٥ صفحات، و٥٠ رسالة لكل محادثة. أي وقفة بتتسجل بسببها (`exhausted` / `capped` / `error`) بدل ما ترجع صندوق فاضي كأنه الحقيقة.

الرسائل اللي بتيجي بالقراءة الراجعة بتتخزن كتاريخ: مفيش `message.received`، فالوكيل مش بيرد على رسالة قديمة، وعدّاد غير المقروء ونافذة الـ٢٤ ساعة بياخدوا أرقام ميتا نفسها بدل «دلوقتي».

## اللي ميتا وقّفته: الموافقة على الرسائل التسويقية (opt-in / opt-out)

صفحة ميتا الرسمية (Marketing Messages، المعروفة بـ Recurring Notifications) بتقول حرفيًا:

- الخدمة **هتتوقف في ١٠ فبراير ٢٠٢٦**.
- من ١ سبتمبر ٢٠٢٥ الوصول بقى **محصور على الشركاء والعملاء الحاليين، وممنوع أي تكامل جديد**.
- البديل (Marketing Messages on Messenger API) هو نفس الباب المقفول على التكاملات الجديدة.

يعني زرار «اطلب موافقة على رسائل تسويقية» في نوفمبر ٢٠٢٦ هو زرار ميتا هترفضه. عشان كده الحالة في `capability_states.py` اسمها `marketing_optin` وحالتها `unsupported_by_api` ومعاها السبب والتاريخ، مش `not_implemented` (اللي معناه إننا اللي قصّرنا).

## حاجات مالهاش API أصلًا

- **مين مالك المحادثة (primary / secondary receiver)**: إعداد في App Dashboard، ميتا مابتديش API لتغييره.
- **نافذة الـ٢٤ ساعة**: مش إعداد، هي قاعدة. الكود بيحترمها وبيستخدم `HUMAN_AGENT` لما شخص حقيقي يكتب في النافذة الممتدة.
