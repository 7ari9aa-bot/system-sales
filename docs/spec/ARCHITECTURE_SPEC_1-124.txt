تمام. دي النسخة التي أعتبرها **Architecture Source of Truth بعد دمج كل الـ40 نقطة والتكرارات**، وليست مجرد قائمة أفكار. حافظت فيها على المبدأ الأصلي أن الـFrontend طبقة تطبيق/عرض فوق الـFastAPI والـDomain، وأن PostgreSQL هي مصدر الحقيقة، وRedis Streams هو event backbone وليس database بديلة. 

# FINAL SYSTEM ARCHITECTURE — SOURCE OF TRUTH

اعتبر هذه الوثيقة الـArchitecture النهائية للنظام.

أي implementation يجب أن يحافظ على الـboundaries والـcontracts المذكورة هنا.

لو احتجت تغييرًا جوهريًا في Architecture، يتم توثيقه كـADR قبل تنفيذه، ولا يتم تغيير الـboundaries بشكل عشوائي أثناء التطوير.

# 11. RLS — REQUIRED

Application-level tenant filtering وحده غير كافٍ.

PostgreSQL RLS هي defense-in-depth.

مهم جدًا:

لا تستخدم privileged/service role الذي bypasses RLS لتنفيذ كل tenant-scoped business queries.

التصميم المطلوب:

```text
Backend Request
↓
resolve tenant
↓
open transaction
↓
set transaction-scoped tenant context
↓
queries execute under RLS
```

الـRLS policies تستخدم tenant context للتحقق.

الـprivileged role يستخدم فقط لحالات إدارية/maintenance/migrations التي تحتاج ذلك، وليس كمسار business عادي.

# 20. REDIS STREAMS

Redis يستخدم:

```text
XGROUP
XREADGROUP
XACK
XPENDING
XAUTOCLAIM / claim mechanism
```

نستخدم Consumer Groups.

مثال:

```text
orders:
    analytics-consumer
    notification-consumer

messaging:
    ai-consumer
    automation-consumer
    realtime-consumer
```

Consumers تعمل at-least-once delivery.

لذلك:

```text
Consumers MUST be idempotent.
```

Redis Stream ليس source of truth.

# 121. FINAL PRINCIPLES

## Principle 1

```text
Frontend never becomes source of truth.
```

## Principle 2

```text
AI never bypasses the domain.
```

## Principle 3

```text
n8n never owns core business truth.
```

## Principle 4

```text
Redis is not the database.
```

## Principle 5

```text
RLS is defense-in-depth.
```

## Principle 6

```text
Every side effect must be idempotent.
```

## Principle 7

```text
Every critical mutation must be auditable.
```

## Principle 8

```text
Every external provider is behind an adapter.
```

## Principle 9

```text
Modules communicate through contracts/events,
not internal repositories.
```

## Principle 10

```text
System depth ↑
Screen complexity ↓
```
