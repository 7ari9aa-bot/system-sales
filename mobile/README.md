# Fihrist Mobile (تطبيق الجوال)

تطبيق الجوال لنظام **فهرست (Fihrist - Sales OS)**.

## الأهداف والمعمارية المقترحة
- **المنصات المستهدفة:** Android & iOS.
- **التكامل مع النظام:** يتصل مباشرة بالـ Backend (`/api/v1/`) بنفس عقود الـ API الموثقة في `docs/` و `desktop/openapi.lock.json`.
- **دعم اللغة العربية:** واجهة مستخدم عربية بالكامل (RTL-first) مع دعم التبديل للإنجليزية.
- **أهم الخصائص المخططة:**
  1. **الكاشير المتنقل (Mobile POS):** بيع سريع وإصدار فواتير من الجوال عبر الكاميرا لقراءة الباركود، أو التوصيل بطابعات بلوتوث محمولة (ESC/POS Bluetooth).
  2. **صندوق الوارد والمحادثات (Mobile Inbox):** إدارة محادثات واتساب، انستجرام، وتيليجرام أثناء التنقل.
  3. **لوحة التحكم والمبيعات (Live Dashboard):** متابعة فورية للإيرادات وحالة الطلبات وتنبيهات المخزون لحظياً (Push Notifications).
